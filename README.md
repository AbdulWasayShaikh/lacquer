# LACQUER, detailing studio

A demo website for an invented car detailing studio in Karachi, designed and built by Abdul Wasay Shaikh.

- Plain HTML, CSS and vanilla JavaScript, with three.js, GSAP, ScrollTrigger and Lenis for the 3D scroll journey.
- The paint effects (swirled clear coat, correction wipe, film edge, ceramic beads) are a custom shader patch on the car's body material.
- 3D car model: Ferrari 458 Italia by vicent091036 (Sketchfab), as shipped in the three.js examples.

The brand, prices, address, hours, customer quotes and warranty figures are invented for the demo. The booking form sends nothing.
